# 改修の検証記録

検証日: 2026-09-08。ローカル環境: macOS、Node.js 26.8.1。GitHub Actionsの設定はNode.js 24です。リポジトリー上の実装とローカル検証を完了し、コミット・push・GitHub Pagesへのデプロイは実行していません。

## 実装した内容

- Astroの静的生成で日英14ページを独立したHTMLとして出力。Reactはビルド時のみ使用。
- 旧ハッシュURLから新URLへの互換処理、各ページの言語リンク、ネイティブのページ内リンク、実際の404。
- 本文をMarkdown／JSONへ分離し、型・翻訳・論文ID・参照の整合性を検証。
- ページ別メタ情報、canonical、hreflang、OGP画像、構造化データ、サイトマップ。本番はindex、開発・404はnoindex。
- CSS・依存関係の削減、AVIF/WebP画像、トップページだけのアニメーションと停止制御。
- JavaScriptに依存しないメニュー／FAQ、キーボード操作、フォーカス表示、文字拡大時の折り返し。
- Google地図・フォームを明示的な操作後に読み込み。既存の外部リンクを保持し、問い合わせページにも教員のメールリンクを掲載。
- PRで検証し、mainの検証成功後のみ公開するGitHub Actions。依存関係の更新はDependabotでPR化。

ブラウザーテストでは、直接アクセス・再読み込み、日英切り替え、履歴、旧URL、404、JavaScript無効時の全ページ・メニュー・FAQ、画像の読み込み、ダークテーマ保存、スキップリンク、Escape操作、動きを減らす設定、画面外でのアニメーション停止を検証しました。全14ページを幅320・390・768・1440pxで確認し、幅640pxで文字サイズ200%にした場合も横はみ出しがないことを確認しています。

地図・フォームは読み込み前に外部通信がないことと、クリック後の埋め込み表示・解除を検証しました。テストではGoogleからの応答を模擬し、実際の問い合わせ送信は行っていません。Google側の障害・フォーム設定や実際の送信完了はこのテストの対象外です。

## 容量とローカル性能

| 指標                                   |            改修前 |                 改修後 |
| -------------------------------------- | ----------------: | ---------------------: |
| トップで実行するJavaScript（gzip換算） |     109,386 bytes |            2,250 bytes |
| トップで読み込むCSS（gzip）            |      34,137 bytes |            7,394 bytes |
| 教員写真1枚                            | 約110–120 KiB PNG | 約7.5–7.9 KB AVIF/WebP |
| LCP・3回の中央値                       |          1,272 ms |                 468 ms |
| 初期表示CLS・3回の中央値               |                 0 |                      0 |
| 観測期間中の長いタスクの合計・中央値   |            187 ms |                   0 ms |

実行JavaScriptは外部ファイルとインラインのgzip換算値を合算し、JSON-LDを除外しました。インライン部分はHTML全体とは別に圧縮して比較しています。改修後のトップは外部JavaScriptを要求せず、必要な処理だけをHTMLに含みます。Reactのクライアント用ファイルはビルドに含まれますが、HTMLから参照されず、実際のリクエストにもありません。

条件: Chromium 153、390×844px、DPR 3、CPU4倍スロットリング、下り1.6Mbps、上り0.75Mbps、遅延150ms。各回は新しいブラウザーコンテキストでキャッシュを無効にし、load後2秒まで観測しました。改修前後を同じローカル静的配信で3回ずつ測定しています。比較元のビルドは改修開始時に一時ディレクトリーへ保存しました。

生データは [performance.json](performance.json)、改修前の容量記録は [baseline.json](baseline.json) にあります。`npm run test:performance` で現在のビルドを再計測できます。過去版との比較には `BASELINE_DIST` で過去のdistを別途指定してください。

この結果はローカルのラボ計測であり、実利用者のINP、Core Web Vitals合格、Lighthouseスコアを示すものではありません。公開後の性能は配信環境や端末でも変わります。アクセシビリティの自動検査も適合認証ではありません。実機・支援技術での継続確認を推奨します。

GitHub ActionsのYAMLは構文確認済みですが、GitHub上での実行と公開URLの確認はpush後に行う工程です。
